# Expense Claim App

- Baca [aturan kerja](.github/copilot-instructions.md) dan [aturan bisnis](docs/business-rules.md).
- Pasang paket dengan `npm ci`; jalankan `npm run lint`, `npm test`, dan bila UI berubah, `npm run e2e`.
- Baseline punya latihan P5: test kalender sengaja gagal di Los Angeles. Jangan mengubahnya di skenario lain; jelaskan hasil Jakarta dan LA secara terpisah.
- Kerjakan hanya issue yang ditunjuk. Jangan merge, push ke `main`, mengubah pengaturan, mengalihkan tugas ke repo lain, atau menyentuh rahasia.
- Jangan ubah `issues/`, `docs/screenshots/`, dan `site/` kecuali diminta. Simpan bukti nyata terpisah dari ilustrasi.
