# Demo S06 dan S14 di organisasi (opsional)

Repo personal dipakai untuk demo utama. Pengaturan Jira/Teams, kebijakan enterprise, dan dashboard organisasi bukan bagian dari verifikasi repo personal.

1. Admin membuat repo latihan dari template `sandy-gunawan/agenticSDLC`; pilih visibilitas sesuai kebijakan organisasi. Periksa repo sebelum memberi akses.
2. Admin mengecek lisensi dan policy Copilot cloud agent, GitHub Actions, serta integrasi Jira/Teams yang disetujui. Jangan memakai token personal yang tidak disetujui organisasi.
3. Untuk S06, delegasikan ticket latihan perubahan label; catat link balik ke draft PR. Di akun personal, gunakan issue S06.
4. Untuk S14, jalankan test hook dengan sinyal inert. Bila memiliki izin, buka dashboard penggunaan; samarkan identitas dan angka akun sebelum memakai screenshot di workshop.
5. Untuk gh-aw, ikuti [referensi autentikasi](https://github.github.com/gh-aw/reference/auth/). Gunakan `WORKSHOP_AI_ENABLED` hanya selama sesi dengan jadwal dan budget yang disetujui.

Belum ada tangkapan layar tenant organisasi. Jangan memakai screenshot akun lain sebagai bukti integrasi ini.
