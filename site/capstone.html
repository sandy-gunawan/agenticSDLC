WORKSHOP / AGENTIC SDLC

Capstone: klaim multi-currency

Ikuti epik IDR, USD, dan SGD dari issue sampai manusia siap memutuskan merge.

Delapan tahap

  1. Bagi epik menjadi tugas

    Lina + Planner

    Pilih issue multi-currency. Pisahkan ADR, aplikasi, test, dan docs.

    Belum di-capture · S15-02-breakdown.png

  2. Setujui desain

    Bima + Architect

    ADR menetapkan sumber kurs, rounding, approval, dan perilaku retry. Bima menyetujui desain.

    Belum di-capture · S15-03-adr.png

  3. Implementasikan di branch

    Coding agent

    Agent mengerjakan satu tugas di branch dan membuka draft PR. Belum ada merge.

    Belum di-capture · S15-04-pr.png

  4. Periksa CI

    GitHub Actions

    Jalankan lint, test dua timezone, dan Playwright. Selidiki kegagalan sebelum lanjut.

    Belum di-capture · S15-05-ci.png

  5. Review perubahan

    Review Board + CodeQL

    Pisahkan temuan performa, security, dan kepatuhan. Validasi hasil pemindaian.

    Belum di-capture · S15-06-reviews.png

  6. Ambil keputusan merge

    Tech Lead

    Hanya manusia yang merge di repo turunan setelah approval dan checks terpenuhi.

    Belum di-capture · S15-07-merge.png

  7. Sinkronkan docs

    Docs sync + triage

    Workflow yang diizinkan membuka draft PR docs. Issue lanjutan bisa ditriase.

    Belum di-capture · S15-08-docs.png

  8. Periksa audit

    Ibu Maya + Yoga

    Bandingkan metadata audit dan dashboard biaya. Jangan salin isi rahasia.

    Belum di-capture · S15-09-audit.png
