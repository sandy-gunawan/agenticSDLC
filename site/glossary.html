WORKSHOP / AGENTIC SDLC

Glosarium & FAQ

Istilah yang diperlukan untuk mengikuti workshop, dan jawaban untuk PM, dev, serta CISO.

Glosarium

Coding agent
Agent GitHub yang mengerjakan task di lingkungan terpisah dan mengembalikan draft PR.
Custom agent
Profil spesialis dengan instruksi dan batas tools yang berbeda.
Skill
Prosedur yang dimuat saat sebuah pekerjaan membutuhkannya.
MCP
Protokol untuk menghubungkan agent ke layanan atau alat dengan izin yang sesuai.
Hook
Pemeriksaan yang berjalan pada titik tertentu, misalnya sebelum tool dipakai.
gh-aw
Compiler Agentic Workflows: Markdown menjadi workflow GitHub Actions.
Safe outputs
Daftar perubahan GitHub yang boleh diminta agent, dijalankan di job terpisah.
AI credit / premium request
Satuan penggunaan yang ditampilkan produk dan bergantung pada paket. Jangan disamakan dengan jumlah commit atau test.
Branch protection
Aturan yang memblokir merge sampai review dan checks terpenuhi.
ADR
Catatan keputusan arsitektur: pilihan, alternatif, dan akibatnya.

Pertanyaan umum

Apakah agent boleh merge sendiri?

Tidak dalam workshop ini. Tech Lead yang memutuskan setelah review dan checks.

Mengapa tidak semua hal dilakukan otomatis?

Keputusan bisnis, akses, dan risiko perlu pemilik yang bisa menolak atau meminta revisi.

Apa yang bisa dilakukan PM tanpa Jira?

Tulis issue GitHub dengan hasil yang diharapkan dan aturan kapan pekerjaan dianggap selesai.

Apakah localhost punya autentikasi sungguhan?

Tidak. Pemilih akun hanya untuk data fiktif dan server bind ke loopback.

Mengapa test LA merah?

P5 sengaja mencampur hari lokal dan UTC. S05 memperbaiki test, bukan menyembunyikan kegagalan.

Apa bedanya scan selesai dengan alert tertutup?

Scan selesai berarti analisis berjalan. Alert tertutup perlu bukti temuan dan perbaikan; S10 tidak membuat keduanya secara artifisial.

Apakah hook ini cukup untuk produksi?

Tidak. Hook adalah contoh tambahan. Tetap perlu izin minimum, review manusia, sandbox, dan kebijakan repo.

Bagaimana membaca biaya?

Gunakan dashboard untuk pemakaian dan tarif akun yang berlaku. Angka ilustrasi bukan tagihan.

Bagaimana mengulang tanpa mengubah main?

Reset hanya membersihkan worktree lokal yang bersih. Buat repo turunan baru untuk capstone yang sudah di-merge manusia.
