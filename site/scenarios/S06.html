S06 / SKENARIO

Delegasi dari Jira atau Teams

Gunakan issue GitHub sebagai alternatif personal. Tautkan PR ke ticket bila integrasi aktif.

Level 2LinaRaniSebagian butuh org

Durasi 6 menit · estimasi latihan

Sudut pandang

Cerita tim

Lina tulis ticket "ubah label tombol & tambah tooltip". Harus tunggu sprint planning, di-assign, dev buka Jira lalu GitHub, Lina cek lagi di Jira.

Kerugian

Perubahan 15 menit butuh 2 minggu lead time; PM merasa dev lambat, dev merasa diganggu — gesekan antar tim.

Angka dalam cerita adalah ilustrasi, bukan hasil dry-run.

Yang disiapkan di repo

P6 — label "Submit", tanpa tooltip.

Lihat file dan kontrak

issues/S06.md

Tombol Submit → Ajukan Klaim dengan petunjuk

Pilihan solusi

Delegasi langsung dari Jira / Azure Boards / Teams ke coding agent; hasil tetap terlacak di PR.

  1. Lina menyiapkan konteks.
  2. Agent mengerjakan latihan S06.
  3. Manusia memeriksa: Gunakan issue GitHub sebagai alternatif personal. Tautkan PR ke ticket bila integrasi aktif.

Langkah demo

  1. Baca issue latihan dan kriteria selesai.
  2. Gunakan prompt atau perintah berikut. Prompt atau perintah
    Ubah label Submit menjadi Ajukan Klaim dan buat petunjuk yang bisa dibaca dengan keyboard.
  3. Periksa hasil: Gunakan issue GitHub sebagai alternatif personal. Tautkan PR ke ticket bila integrasi aktif.
