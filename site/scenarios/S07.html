Sudut pandang

Cerita tim

Modul export CSV pakai library deprecated, 0 test. Tiap tahun proposal migrasi ditolak: "terlalu berisiko, tidak ada test".

Kerugian

Biaya extended support, sulit rekrut, security tidak ter-patch, biaya makin besar tiap tahun ditunda.

Angka dalam cerita adalah ilustrasi, bukan hasil dry-run.
