S12 / SKENARIO

Docs sync

Setujui penggunaan AI di repo latihan terlebih dulu. Periksa path pada draft PR.

Level 4Bima

Durasi 6 menit · estimasi latihan

Sudut pandang

Cerita tim

Tim API ubah format response, lupa update docs. Tim mobile dan partner integrasi pakai docs lama, aplikasi mereka error di produksi.

Kerugian

Insiden lintas tim, debugging dua pihak, kepercayaan partner rusak.

Angka dalam cerita adalah ilustrasi, bukan hasil dry-run.

Yang disiapkan di repo

P12 — docs/api.md beda dengan kode GET /claims.

Lihat file dan kontrak

.github/workflows/docs-sync.md

Kontrak lama memakai items → Draft PR hanya memperbarui docs/api.md

Pilihan solusi

gh-aw docs-sync.md (trigger push + schedule, permissions: contents: read, safe-outputs: create-pull-request) membandingkan kode vs docs dan membuka draft PR.

Langkah demo

  1. Baca issue latihan dan kriteria selesai.
  2. Gunakan prompt atau perintah berikut. Prompt atau perintah
    gh workflow run docs-sync.lock.yml --ref main
  3. Periksa hasil: Setujui penggunaan AI di repo latihan terlebih dulu. Periksa path pada draft PR.
